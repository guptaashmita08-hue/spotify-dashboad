# spotify-dashboad
Spotify Music Analytics Dashboard
📊 Project Overview
An interactive Spotify Music Analytics Dashboard created using Microsoft Power BI to analyze songs, artists, popularity, album types and monthly trends.
🛠️ Tools Used
Power BI
DAX
Data Cleaning
Data Visualization
📈 Key Insights
Song popularity analysis
Songs by artist
Songs by album type
Explicit vs Non-Explicit songs
Average popularity by month
Distinct songs by month
Average total tracks by song
🎯 Objective
To analyze Spotify music data and create an interactive dashboard that provides meaningful insights through data visualization.
